# 画像変換

ブラウザー内で画像を変換するローカル処理アプリです。画像の読み込みと変換は専用 Web Worker 内の Rust/WebAssembly エンジンで行い、画像データをサーバーへ送信しません。変換に外部 API、CDN、外部フォントは使いません。

## 完成済み配布物を起動する

### Windows

`dist` を含む配布物を入手済みの場合は、`START.cmd` をダブルクリックします。`dist` を `127.0.0.1` のローカル HTTP サーバーで配信し、ブラウザーを開きます。ポート 4173 が使用中の場合は、4174 以降の空きポートを使います。起動時に Node.js、Rust、インターネット接続は不要です。終了するには起動したコンソールで `Ctrl+C` を押します。

### その他の OS

`dist` ディレクトリを含む配布物を入手するか、下記の手順でビルドし、そのディレクトリを静的 HTTP サーバーで配信してください。WebAssembly ファイルの MIME 型は `application/wasm` に設定します。`dist/index.html` を `file://` で直接開く方法は、ブラウザーの Worker / WebAssembly 制限により利用できません。

## 基本操作

1. ファイルを選択するか、画面へドロップします。
2. サイズ、形式、ページ・フレーム数、解析結果を確認します。
3. 複数ページ・フレームは「すべて」または `1,3-5` のような範囲で選びます。番号は 1 から始まります。
4. 出力形式と設定を選び、「変換する」を実行します。
5. 出力を個別に保存するか、ZIP でまとめて保存します。

アニメーションの各フレームは、独立した静止画像として出力されます。アニメーションを保った出力には対応していません。RAW、PSD、AI、PDF、DICOM は入力専用です。

キーボード操作: `Ctrl+O` でファイル追加、`Ctrl+Enter` で変換、`Esc` で変換キャンセル。テーマは画面右上で切り替えます。

## 対応形式と制限

入力・出力形式ごとの対応範囲、画像サイズ上限、例外、検証範囲は[対応形式と制限](docs/SUPPORT.md)を参照してください。

## 開発・再ビルド

完成済みアプリの起動には開発ツールは不要です。ソースからビルドする場合は、Node.js/npm、`engine/rust-toolchain.toml` に記載された Rust、`wasm-pack` が必要です。依存パッケージの初回取得にはインターネット接続が必要です。

```powershell
npm ci
Set-Location engine
wasm-pack build --target web --out-dir ../public/wasm
Set-Location ..
npm run build
.\START.cmd
```

`package-lock.json` と `engine/Cargo.lock` は依存バージョンを固定するためのファイルです。UI と変換エンジンの構成や開発時の設計方針は[開発者向け設計メモ](docs/DESIGN_SYSTEM.md)を参照してください。

## 仕様上の補足

- 画像は 8-bit sRGB に変換される形式があり、HDR の階調や一部のメタデータ・編集情報は保持されません。
- SVG の文字描画には同梱 Noto Sans を使います。フォントにない文字は欠落することがあるため、必要に応じて元 SVG で文字をパス化してください。
- 選択したファイルと変換結果は端末のメモリに保持し、保存は利用者のダウンロード操作で行います。
- ローカル起動サーバーは `127.0.0.1` のみで待ち受け、GET/HEAD による静的配信のみを行います。画像アップロード機能はありません。
